# Пояснение к графикам

Использованы миграции, из ../migrations/migrations-k6-test.

Запросы к Telegram api невозможны, что объясняет бизнесс метрики и перцентили в bot.

Тестовые данные содержат несуществующие github repositories, так что параметризованный dashboard с 
корреляцией между первоначальм возврастающим количеством запросов(которые естественно отклоняются) 
и соответственно возврастающим количество ошибок(видно на графиках они схожи) естественно.

Затухание запросов связано с работающими circuitbreaker, rateLimiter.
